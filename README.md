# 📊 Student Screen Time Analysis Project

## 📌 Project Overview

This project analyzes how student habits such as screen time, study hours, and extracurricular activities affect academic performance.

The goal is to identify key factors that influence test scores using Excel based data analysis techniques.

---

## 📂 Dataset Details

The dataset contains information about students including:

* Student ID
* Age
* Gender
* Study Hours
* Screen Time
* Extracurricular Activities Time
* Test Scores

---

## 🧹 Data Cleaning Steps

* Checked for missing values in Test Score column
* Removed or replaced missing values using average
* Verified data consistency
* Ensured correct data types

---

## 📊 Analysis Performed

### 1. Screen Time vs Test Scores

* Created pivot table
* Calculated average scores for different screen time groups
* Found weak relationship

### 2. Study Hours vs Test Scores

* Created pivot table
* Observed strong positive trend
* More study hours lead to higher scores

### 3. Extracurricular Activities vs Scores

* Analyzed activity time impact
* Found minimal effect on performance

---

## 📈 Dashboard Features

* KPI metrics

  * Total Students
  * Average Score
  * Average Screen Time
  * Average Study Hours

* Visual charts

  * Screen Time vs Scores
  * Study Hours vs Performance
  * Activities vs Scores

* Interactive filters using slicers

---

## 🔍 Key Insights

* Study hours have the strongest impact on student performance
* Screen time shows very weak relationship with scores
* Extracurricular activities have minimal influence
* Data cleaning is important due to missing values

---

## 🛠 Tools Used

* Microsoft Excel
* Pivot Tables
* Charts
* Data Cleaning Techniques

---

## 🚀 Conclusion

The analysis shows that academic success is mainly driven by study habits rather than screen time or extracurricular activities. Proper data cleaning and visualization help in generating meaningful insights.

---

## 📎 Future Improvements

* Use Power BI for advanced dashboards
* Apply statistical models for deeper insights
* Include larger and more diverse datasets

HEALTHY FUTURES – Child Nutrition & Growth Dashboard


 📌 Project Overview

This project analyzes **child nutrition and growth patterns** using Microsoft Excel. The goal is to understand how factors like **BMI, sugar consumption, screen time, age, and region** influence children's health status.

Using **data cleaning, pivot tables, and interactive dashboard visualizations**, the project provides actionable insights to monitor and improve child health outcomes.

---

 🎯 Project Objectives

- 📊 Analyze children's **health status (Healthy vs Underweight) ** across age groups  
- 🍭 Evaluate the impact of **sugar drink consumption on health**  
- 📱 Study the relationship between **screen time and child growth**  
- 👶 Identify **age-wise nutrition trends (24–60 months) **  
- 🌍 Compare **regional distribution of children**  
- 📈 Build an **interactive dashboard for data-driven insights**

---

 🗂 Dataset Information

| Column Name            | Description                                      |
|----------------------|--------------------------------------------------|
| Child_ID             | Unique identifier for each child                 |
| Age Months           | Age of child (in months)                       |
| Gender               | Male / Female                                   |
| Region               | Geographic region (Central, East, North, etc.)  |
| BMI                  | Body Mass Index of child                        |
| Health Status        | Healthy Weight / Underweight                    |
| Daily_Sugar_Drinks   | Average sugar drinks consumed per day           |
| Screen_Time_Hours    | Average daily screen time (hours)              |

---

🧹 Data Cleaning Process

- 🧼 Removed duplicate records
