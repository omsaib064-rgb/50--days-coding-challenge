## 🎯 Project Objective

Analyse the **Mahatma Gandhi National Rural Employment Guarantee Scheme (MGNREGS)** — one of India's largest rural employment programmes — to uncover trends, efficiency gaps, and state-level performance patterns across financial years 2017 to 2021.

## 🗃️ Dataset Description

### Raw Columns (Original CSV)

| Column | Description | Unit |
|---|---|---|
| `Year` | Financial year | Integer (2017–2021) |
| `State` | Indian state name | Text |
| `Households_Demanded` | HH that requested work under MGNREGS | Count |
| `Households_Provided` | HH that were actually given work | Count |
| `Person_Days_Generated` | Total person-days of employment created | Days |
| `Expenditure_Cr` | Total scheme expenditure | Crore (₹) |

### Derived / Engineered Columns (Cleaned Data)

| Column | Formula | Purpose |
|---|---|---|
| `Work_Completion_Rate_%` | `HH_Provided / HH_Demanded × 100` | Efficiency of work allocation |
| `Expenditure_per_PersonDay_Rs` | `Expenditure_Cr × 10M / Person_Days` | Cost efficiency |
| `Households_Unfulfilled` | `HH_Demanded − HH_Provided` | Unmet demand gap |
| `Utilisation_Gap_%` | `Unfulfilled / HH_Demanded × 100` | % of demand not met |
| `Expenditure_per_HH_Rs` | `Expenditure_Cr × 10M / HH_Provided` | Per-household spending |
| `Performance_Band` | High ≥85% / Medium 70–84% / Low <70% | Tiered classification |

---

## 🔧 Data Cleaning Steps

1. **Whitespace Trimming** — Stripped leading/trailing spaces from column names and State values
2. **Data Type Standardisation** — Enforced `int` for Year, `float` for numeric columns
3. **Null Value Handling** — Used median imputation strategy for any missing numerics
4. **Range Validation** — Checked that `HH_Provided ≤ HH_Demanded` and expenditure > 0
5. **Title Case Normalisation** — State names standardised (e.g., `"karnataka"` → `"Karnataka"`)
6. **Outlier Awareness** — Noted UP and Bihar as high-demand states; treated as valid, not outliers

## 🔍 Key Insights

### 1. 📈 All States Show Consistent Year-on-Year Growth
Person-days and expenditure both increased from 2017 to 2021 across all 5 states, indicating expanding programme reach and budget absorption.

### 2. 🏆 Karnataka = Most Efficient State
Karnataka maintained the **highest work completion rate (~90%)** consistently across all years with relatively lower demand — suggesting strong local implementation capacity.

### 3. ⚠️ Bihar & Uttar Pradesh — High Demand, Improvement Needed
These two states have the **highest household demand** for work. While both improved over time, their completion rates remain lower than Karnataka and Tamil Nadu, pointing to implementation challenges at scale.

### 4. 💰 Cost Efficiency Varies
Expenditure per person-day ranged across states. High expenditure states (Uttar Pradesh) need to be cross-referenced with wage rates and inflation to determine whether higher spend equals better outcomes.

### 5. 🚩 Utilisation Gaps Are Persistent
Every state shows a non-zero `Utilisation_Gap_%`, meaning some households requesting work are not being served every year. Bihar showed the largest absolute unfulfilled demand.

## 📐 Calculated Measures Reference

```python
Work_Completion_Rate_%      = HH_Provided / HH_Demanded × 100
Expenditure_per_PersonDay   = Expenditure_Cr × 10,000,000 / Person_Days_Generated
Households_Unfulfilled      = HH_Demanded − HH_Provided
Utilisation_Gap_%           = Households_Unfulfilled / HH_Demanded × 100
Expenditure_per_HH          = Expenditure_Cr × 10,000,000 / HH_Provided

Performance_Band:
  → "High (≥85%)"    if Completion_Rate ≥ 85
  → "Medium (70–84%)" if 70 ≤ Completion_Rate < 85
  → "Low (<70%)"     if Completion_Rate < 70
```
