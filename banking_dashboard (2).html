DAX Measures Reference Power BI DAX
Total Deposits
Total Deposits = CALCULATE( SUM(Transactions[Transaction_Amount]), Transactions[Transaction_Type] = "Credit" )
Total Withdrawals
Total Withdrawals = CALCULATE( SUM(Transactions[Transaction_Amount]), Transactions[Transaction_Type] = "Debit" )
Net Balance Growth
Net Balance Growth = [Total Deposits] - [Total Withdrawals]
Average Account Balance
Avg Account Balance = AVERAGEX( VALUES(Customers[Customer_ID]), CALCULATE(AVERAGE(Transactions[Balance])) )
Loan Default Rate %
Loan Default Rate % = DIVIDE( CALCULATE( DISTINCTCOUNT(Customers[Customer_ID]), Customers[Loan_Status] = "Default" ), CALCULATE( DISTINCTCOUNT(Customers[Customer_ID]), Customers[Account_Type] = "Loan" ) ) * 100
Monthly Transaction Volume
Monthly Txn Volume = CALCULATE( SUM(Transactions[Transaction_Amount]), DATESMTD(Calendar[DateKey]) )
Net Transaction Impact
Net_Transaction_Impact = IF( Transactions[Transaction_Type] = "Credit", Transactions[Transaction_Amount], -Transactions[Transaction_Amount] )
Customer Profitability Score
Profitability Score = Transactions[Balance] + Transactions[Net_Transaction_Impact]
Age Group (Calculated Column)
Age Group = SWITCH(TRUE(), Customers[Age] <= 30, "18-30", Customers[Age] <= 50, "31-50", "51+" )

5. Calendar Table
